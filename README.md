# CPU Instruction Cycle Simulator

## About the Project
This is an interactive web-based project developed for the Computer Organization and Architecture (COA) micro-project. It demonstrates the three main stages of the CPU instruction cycle: Fetch, Decode, and Execute.

## Features
- Interactive instruction selection
- ADD, SUB, LOAD, and STORE instructions
- Editable register and memory values
- Step-by-step instruction cycle simulation
- Run All Stages option

## Technologies Used
- HTML
- CSS
- JavaScript

## Objective
To understand the working of the CPU instruction cycle through a simple and interactive simulation.
